# notifications

Creates one Grafana contact point with any combination of Slack, email, Teams
and Webex, and optionally the organization's notification policy tree.

Use it on its own to send alerts from any Grafana rules, not only this
module's, to these channels.

## Usage

```hcl
module "notifications" {
  source = "github.com/Mosher-Labs/terraform-kubernetes-observability//modules/notifications?ref=<commit-sha>"  # vX.Y.Z

  contact_point_name = "platform-alerts"
  email = {
    addresses = ["oncall@example.com"]
  }
  # Leave the policy tree alone if something else manages it.
  manage_notification_policy = false
  slack = {
    recipient = "C0123456789"
    token     = var.slack_bot_token
    username  = "Alerts"
  }
  teams = {
    url = var.teams_workflow_url
  }
}
```

With `manage_notification_policy = true` (the default), critical alerts repeat
every hour and warnings every 4 hours. Change that with `policy`.
